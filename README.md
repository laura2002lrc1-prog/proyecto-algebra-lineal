# Álgebra Lineal • Ejercicios (HTML/CSS/JS + Node/Express + SQLite)

## Qué incluye
- Web con **3 apartados**: Vectores y Espacios, Matrices y Sistemas, Transformaciones.
- CRUD (crear y eliminar) de ejercicios contra **SQLite**.
- Interfaz moderna con tarjetas, buscador, orden y panel lateral.

## Ejecutar
1. Instalar dependencias:
   - En una terminal dentro de `c:/Users/Admin/Desktop/proyecto laura`:
     - `npm install`
2. Iniciar servidor:
   - `npm start`
3. Abrir:
   - http://localhost:3000

Se crea automáticamente `data.sqlite` en la raíz del proyecto.
